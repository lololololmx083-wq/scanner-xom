# Scanner-Xom 

## Advanced Network Port Scanner

A professional and complete port scanner with advanced features for network scanning and service detection!

---

##  Features

###  Scan Modes:
- **Multi-Target Scan** - Scan multiple targets simultaneously
- **Single Target Scan** - Scan a single target
- **Ping Sweep** - Find alive hosts in network
- **Subdomain Scanner** - Find subdomains
- **OS Detection** - Detect OS using TTL
- **Tor Scan** - Scan through Tor network
- **Decoy Scan** - Scan with fake IPs (IP Spoofing)

### ️ Scan Types:
- TCP Scan (Full Connection)
- SYN Scan (Stealth)
- UDP Scan
- FIN Scan
- Fragment Scan

### Security Features:
- SSL/TLS Support for HTTPS
- Tor Support
- IP Spoofing with Faker
- Identity Hiding

###  Output:
- TXT Report
- HTML Report
- Colored Output
- Progress Bar
